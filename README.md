# Forge Gym Dashboard

Een moderne, responsive gym-tracker gebouwd met HTML, CSS en vanilla JavaScript.

## Functies
- Trainingsdagen aanmaken, bewerken en verwijderen
- Oefeningen, gewicht, reps, sets, datum en notities loggen
- Dashboard met statistieken, persoonlijke records en progressie
- Geschiedenis met verwijderbare logs
- Progressiegrafiek per oefening
- Automatische opslag in `localStorage`
- Responsive dark mode interface voor mobiel en desktop

Open `index.html` in een browser om de app te gebruiken. Er is geen build-stap of backend nodig.
